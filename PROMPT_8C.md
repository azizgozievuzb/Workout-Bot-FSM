### Ф2. Бэкенд — сессии: частичный зачёт + антифарм XP (решения §8.1 BACKLOG)
- Красная кнопка фронта переводится с `/cancel` на **`/finish` с частичным done**. `/cancel` остаётся только для stale-cleanup.
- `/finish`: капли И XP начисляются только за ПЕРВУЮ сессию каждого типа в день (антифарм 8b расширить на XP); формула частичная `(done/N)^0.65` работает при раннем выходе. Повторные сессии: капли 0, XP 0, `repeat=true` + случайная фраза поддержки из пула в конфиге (5–8 нейтральных: «Ты молодец!», «Телу — спасибо!», «Красиво идёшь!»…).
- **День закрывает только полная сессия** (`completed_full=true`): правки в finish (закрытие дня) и в closure-джобе. Частичная сессия день НЕ закрывает, даже первая.
- При сломе стрика closure-джоб пишет `lost_streak_len/lost_streak_at` (до обнуления).

### Ф3. Бэкенд — покупки
- `POST /players/me/buy-freeze` — цена `freeze` из app_shop_items, списание drops_balance, `paid_freezes+1` (кап 3 — отказ при переполнении). Атомарно (баланс и кап проверять в одной транзакции/RPC).
- `POST /players/me/restore-streak` — доступен если `lost_streak_len>0` и `lost_streak_at` не старше **72 часов** (допущение, константа в конфиге). Цена `= streak_restore.price × lost_streak_len`, зажатая в `[meta.min, meta.cap]`. Успех: `current_streak=lost_streak_len`, lost_* → NULL.
- Смена графика: в `PATCH /players/me/schedule` вне grace-окна — списание `schedule_change` (внутри grace — бесплатно, как в 8a). Не хватает капель → 400 с ценой в detail.
- **Фото-карточка**:
  - `POST /players/me/card-photo/purchase` — списание `photo_card`, статус «куплено, ждёт фото».
  - `POST /players/me/card-photo/upload` (селфи) + режим: `ai` → photo_styler-стеком генерируются **2 варианта** (гендерный промпт: женственнее/мягче для Ж, брутальнее для М — пол из users.gender) → в `card_photo_candidates`; `raw` → селфи сразу становится `card_photo_url` (source='raw'), в AI не отправляется.
  - `POST /players/me/card-photo/choose` (index) → выбранный вариант в `card_photo_url` (source='ai'), кандидаты очищаются.
  - `POST /players/me/card-photo/reroll` — списание `photo_reroll`, новые 2 варианта взамен.
  - Повторная смена фото позже = снова полный `purchase` (та же цена).
- **Мультяшка-дефолт:** эндпоинты R-панели отдают для игрока `card_photo_url`, а при NULL — путь к мультяшному ассету по полу. Два ассета-заглушки положи в `frontend/public/avatars/` (сгенерируй простые нейтральные SVG/PNG силуэты м/ж; настоящие мультяшки — контент-долг, пометь). Styled-фото игрока НЕ отдавать наставнику больше нигде.

### Ф4. Фронтенд
- **MarketCube игрока — витрина:** шапка с балансом `💧 N` (постоянно видимым — UX-долг №5) + 4 карточки: Unlock light, Lock light, Заморозка (счётчик «в запасе: бесплатных X, купленных Y/3»), Фото-карточка. Цены живьём из app_shop_items. Unlock/Lock — те же дисклеймер-тесты (перенести вызов из PlayerSchedulePanel; из панели расписания кнопки покупки убрать, оставить ссылку «Магазин →»). Заглушки «Оплата Stars / TON скоро» из витрины игрока убрать.
- **Фото-карточка флоу:** покупка → выбор: «✨ Обработать AI» / «📷 Поставить как есть (без AI)» → селфи (камера/галерея) → для AI: экран 2 вариантов → «Выбрать» / «🎲 Ещё 2 варианта (60 💧)» → превью «так тебя видит наставник». Показ текущей карточки в профиле.
- **Restore-плашка:** на Action-кубе при `lost_streak_len>0` в окне 72ч: «💔 Стрик N дней сгорел. Восстановить за X 💧» → подтверждение → восстановление.
- **Смена графика:** вне grace кнопка показывает цену «Сменить за 100 💧».
- **Ранний выход:** красная кнопка → «Закончить досрочно»; модалка: первая сессия дня — «Засчитано X из N → +Y 💧. День НЕ закрыт — пройди полную зарядку/тренировку до конца дня, чтобы спасти стрик»; повторная — «Начисления за сегодня уже получены. День закрывает только полная сессия»; после — карточка «Готово» (частичные цифры или фраза поддержки). UX-долг №7 закрыт этим.
- Бейдж баланса 💧 также на дашборде игрока (PlayerSchedulePanel/Action) — маленький, постоянный.
