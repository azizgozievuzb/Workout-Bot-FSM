### Ф1. Миграция 035 (idempotent, `backend/db/migrations/035_light_mode.sql`, применить через my-supabase)
- `users`: `light_unlocked BOOLEAN NOT NULL DEFAULT false`, `light_active_from DATE NULL` (понедельник, с которого стрик считает «любой день»), `light_locked_at TIMESTAMPTZ NULL`.
- `workout_sessions`: `session_type TEXT NOT NULL DEFAULT 'main'` CHECK ('main','light').
- Новая таблица `app_shop_items` (key TEXT PK, title, price_drops INT CHECK ≥1, is_active BOOLEAN) — seed: `light_unlock`=300, `light_lock`=500. (В 8c сюда лягут остальные карточки витрины; цены редактируются админкой — добавь `GET/PATCH /admin/app-shop-items` по образцу tier-prices.)

### Ф2. Бэкенд
- **Конфиг light** в `workout_config.py`: 4 упражнения (`walk_in_place` ходьба на месте, `knee_raises` подъём коленей, `heel_kicks` пятки к ягодицам, `marching` маршировка), фазы: разминка → 4 × (3 мин работа + 1 мин отдых) → заминка ≈ 20 мин. Клип на упражнение — той же длительности/механики, что в main (остаток интервала — таймер без записи). Gemini-оценка тем же пайплайном.
- **Формула капель light**: `30 × quality × (done/4)^0.65 × streak_mult` (обобщи текущий расчёт по session_type; MAX_DROPS: main 50 / light 30).
- **Антифарм**: капли начисляются максимум за 1 main-сессию + 1 light-сессию в день (по локальной TZ); повторные сессии — 0 капель (сессия сохраняется, XP-оценка показывается).
- **Покупка unlock/lock**: `POST /players/me/light-unlock` и `/light-lock` — списание `drops_balance` по цене из `app_shop_items` (атомарно, баланс < цены → 400); unlock: `light_unlocked=true`, `light_active_from = следующий понедельник` (лок. TZ); lock: `light_unlocked=false`, `light_locked_at=now`, стрик-режим main-only тоже со следующего понедельника (до него light-дни ещё плановые — доиграть неделю честно). Повторный unlock — обычная цена.
- **Плановость дней (расширение 8a)**: если light активен (unlocked И сегодня ≥ light_active_from): плановый = КАЖДЫЙ день (main-дни = main, остальные = light). Closure-джоб: main-день закрывается только main-сессией; **light-день закрывается light ИЛИ main-сессией** (перевыполнение не наказываем). Заморозки работают на любой плановый день (правила 8a без изменений).
- **Уведомления**: в light-день тексты «сегодня лёгкая зарядка» (нейтральные по полу); main-день — как в 8a.
- Стрик в `finish`: закрытие дня по типу сессии в соответствии с правилами выше (раз в день, `last_closed_day` — механика 8a).

### Ф3. Фронтенд + FSM
