### Ф2. Бэкенд — расписание и стрик
- `PATCH /players/me/schedule` — установка/смена 3 main-дней. Правила: смена применяется со следующего понедельника (хранить `pending_main_days` + `effective_from` или рассчитывай на лету — реши по коду); кулдаун 30 дней между сменами; внутри `schedule_grace_until` — без кулдауна и мгновенно. Оплата смены каплями подключится в 8c — сейчас смена бесплатная, но кулдаун-правила работают.
- `PATCH /users/me/timezone` — тихое сохранение детектированной TZ (валидация IANA). Вызывается фронтом при auth; диалог «обновить?» — это 8e, сейчас: если TZ ещё NULL → просто сохранить; если отличается → сохранить detected в отдельное поле `detected_timezone` НЕ меняя рабочую (для 8e).
- **Стрик-правила (принятые допущения, менять нельзя):** капли начисляются за любую тренировку в любой день; стрик закрывается ТОЛЬКО тренировкой в плановый main-день (по локальной TZ юзера); внеплановые дни стрик не трогают. До покупки light (8b) стрик = только main-дни.
- Закрытие дня: почасовой job — для юзеров, у которых локально только что наступила полночь (00:00–00:59), проверить вчерашний день: был плановым и не закрыт тренировкой → списать заморозку (сначала `free_freezes_left`, потом `paid_freezes`) + уведомление «заморозка спасла стрик»; заморозок нет → стрик = 0 + уведомление. NULL timezone → фолбэк UTC. Идемпотентность обязательна (повторный прогон часа не должен списывать дважды).
- Грант заморозок: ежемесячный job 1-го числа: `free_freezes_left = 3` для игроков-женщин, `1` для мужчин (НЕ накапливаются, просто reset). Пол — из поля, найденного в Ф0.
